# 検品

動画を再生して確かめられないので、品質は「静止画を見る」「機械で測る」の 2 つで保証する。どちらか片方では足りない。機械は見た目の良し悪しが分からず、目は 1 フレームの乱れや音量が分からない。

## 1. 見る（作りながら、何度も）

| いつ | コマンド | 何を見るか |
|---|---|---|
| 画面を作ったとき | `node render.mjs --shot 10` | 実物の画面と見比べる。色、余白、文字の大きさ、文言 |
| 1 場面書いたとき | `node render.mjs --sheet 14:26:1` | 流れ。出る順番、消え残り、余白の片寄り |
| 気になる時刻 | `node render.mjs --shot 16.6,22.5` | 等倍で細部。文字切れ、重なり、1px のずれ |
| 場面の切り替え | `node render.mjs --sheet 13.4:14.6:0.1 --cols 7 --w 420` | 切り替えの途中に変な絵がないか。全部の切り替えで行う |
| 全編 | `node render.mjs --sheet 0:90:1.5 --cols 6` | 通しの流れと、場面ごとの見た目のばらつき |

一覧（sheet）は左上から右へ時刻順に並ぶ。書き出した画像は必ず開いて見る（書き出しただけで安心しない）。

見るときの問い:

1. この絵で、最初に目が行くのはどこか。そこは見せたい所か
2. 文字は全部読めるか（切れていない、重なっていない、小さすぎない）
3. 余白は片寄っていないか。空きすぎた場所、詰まりすぎた場所はないか
4. 前の場面の部品が残っていないか。まだ出ないはずの部品が見えていないか
5. 製品の画面は実物らしいか。文言は実物と同じか
6. 直前の絵から何が変わったか分かるか（変化が小さすぎないか、多すぎないか）

## 2. 測る

### レイアウトの検査（作りながら）

```sh
node render.mjs --lint
```

全編を 0.25 秒おきに調べ、0.5 秒以上続くものを報告する。`✗` は直す。`△` は理由があれば残してよい。

| 表示 | 意味 | 直し方 |
|---|---|---|
| `text-offstage` | 文字が画面の左右からはみ出している | 見出しを短くする、2 行に分ける、`size: "sm"` にする |
| `text-clipped` | 文字がタイルやカードの枠で切れている | 文言を短くする。枠を広げる |
| `caption-overlap` | 見出しが入れ物や部品に重なっている | 見出しの `y`、入れ物の位置を変える。見出しを短くする |
| `caption-tight` | 見出しと部品の間が 28px 未満 | 40px 以上あける |
| `device-small` | 入れ物が 0.85 倍未満で置かれている | 1.0 倍以上にするか、見せたい所へ寄る |
| `ui-text-small` | 入れ物の中の文字が画面上で 17px 未満 | 入れ物を大きく置く、中の文字を大きく作る、寄る |
| `empty-frame` | 背景以外に何も映っていない時間がある | 意図した間（0.5 秒まで）でなければ、前後の退場と登場を重ねる |

この検査で分かるのは機械的な崩れだけ。「異常なし」は「見た目が良い」を意味しない。

### 動画の検品（下見と本番の後）

```sh
node tools/qa.mjs                 # out/video.mp4
```

| 表示 | 意味 | 直し方 |
|---|---|---|
| 形式（H.264 / yuv420p、BT.709、AAC 48 kHz） | どの環境でも再生でき、色がずれない | `render.mjs` をそのまま使えば合う |
| 音量 | -15 LUFS 前後が正常 | `render.mjs` が自動でそろえる。外れるなら曲の区間を確認 |
| ピーク | -0.3 dBTP 以下が正常 | 同上 |
| 無音の区間 | 途中に 1.5 秒以上の無音 | 曲の区間にすき間がないか確認 |
| フレーム数 | 秒数 × fps と合っているか | 合わないなら撮影が途中で止まっている。`--resume` で続きを撮る |
| 1 フレームだけの乱れ | 前後と違う絵が 1 枚だけ挟まっている | その時刻の前後を 0.05 秒きざみで見る。`tl.set` の時刻のずれ、隠し忘れ、`tl.fromTo` の開始前の値が原因のことが多い |
| コマ落ち | 動きの途中に同じ絵が挟まっている | `onFrame` の中の処理が時刻だけで決まっているか確認 |
| 真っ黒な区間 | 途中に黒い絵 | 場面の切り替えで全部の部品を隠していないか確認 |
| 止まった絵 | 2.5 秒以上ほぼ動かない | 読ませる間でなければ、小さく動くもの（回る印、数字、点滅）を足す |

## 3. よくある不具合

実際に起きたものを、起きやすい順に。

| 症状 | 原因 | 直し方 |
|---|---|---|
| 見出しの最後の文字が切れる | 1 行が長すぎて、見出しの幅を超えた | 短くする。`size: "sm"`。2 行に分ける |
| 見出しのすぐ下に入れ物が来て窮屈 | 2 行の見出しは高さ約 320px ある | 見出しを上へ（y 116）、入れ物を下へ（y 490〜）。または見出しを 1 行に |
| 部品が出番の前に一瞬見える | `tl.fromTo` を登場に使った | `tl.in` にする |
| 2 度めに出した部品の出方が変 | 1 度めの `tl.in` の状態が残っている | `tl.set(…, { autoAlpha: 0 })` → `tl.fromTo` で出す |
| 新しい画面が、前の画面の下に出る | 重なりの順（z-index）が逆 | 後から出る画面の z-index を上げる |
| 会話や一覧の先頭が、上で半端に切れる | 行が増えて、入れ物の高さを超えた | 古い行は上に流してよいが、切れ目が目立つなら上端を薄く消す（`mask-image: linear-gradient(to bottom, transparent 0, #000 18px)`）。または行を減らす |
| 別の画面の部品の見た目が変わる | 短いクラス名がぶつかった | 画面の根のクラスの下に書き直す |
| 2 つの画面で同じはずの文言が違う | 片方だけ書き換えた | 中身のデータを 1 か所（配列）にまとめ、両方をそこから作る |
| スマホの中の文字が読めない | 1.1 倍のスマホの 13px は、画面上で 14px | その場面は寄る（1.5 倍）。または見出しで内容を言う |
| 文字が震えて見える | 文字のある部品を数秒かけて動かした | 1 秒ほどで動かしきる。じわじわ動かさない |
| ロゴの色が切り替えの瞬間に変わる | 暗い場面の色のまま飛んできた | ロゴだけ先に明るい場面の色にする（見本の `logo()` を参照） |
| 最後が唐突に切れる | 暮れ（`fadeToBlack`）がない、または短い | `fadeToBlack(T.total - 1.3)` を入れる |

## 4. 本番の書き出し

```sh
node render.mjs --scale 2 --keep-frames        # 裏で走らせる（90 秒で 30〜40 分）
node tools/qa.mjs
node tools/extras.mjs web                      # 10 MB 未満の版
node tools/extras.mjs poster 15.9              # 見出し用の静止画（いちばん内容が伝わる時刻を選ぶ）
```

- 長い撮影は裏で走らせ、終わるまで別の確認を進める。止まったら `--resume --reuse-audio` で続きから
- 本番の後に直したくなったら、該当区間のフレームだけ消して撮り直す。例: 46.5〜47.6 秒なら `out/frames/` の `002790.png`〜`002856.png`（秒 × 60）を消して `node render.mjs --scale 2 --keep-frames --resume --reuse-audio`。音を変えたときは `--reuse-audio` を外す
- 色が合っているかは、最後のカードの 1 フレームを動画から取り出し、撮影した PNG と同じ画素の色を比べれば分かる（1〜2 の差なら正常）
- できた動画は依頼者の言う場所へ置く。`out/` は Git の管理外なので、残すものは外へ複製する

## 5. 出す前の確認

- [ ] 全部の場面の切り替えを 0.1〜0.2 秒きざみで見た
- [ ] `--lint` に `✗` がない
- [ ] `tools/qa.mjs` に `✗` がない（本番の動画で）
- [ ] 動画に出した事実・数値・文言の出どころを言える
- [ ] 他社のロゴを描いていない。断り書きがある
- [ ] 音を消して見出しだけ追っても、話が通じる
- [ ] 軽量版と静止画を作った

## 6. 報告の型

```
## できたもの
- out/video.mp4（90 秒・1920×1080・60fps・音声あり・13.9 MB）
- out/video-web.mp4（1280×720・30fps・9.8 MB）、out/poster.png

## 構成
（場面と見出しを 1 行ずつ）

## 確かめたこと
- 映像: 全フレームを自動検査し、1 フレームの乱れ・コマ落ちなし。レイアウト検査も異常なし
- 音: -15.1 LUFS、ピーク -1.2 dBTP

## 確かめられていないこと
- 音は聴いていません（数値のみ）。曲の好みと音量の釣り合いは、聴いて判断をお願いします
- （資料から確かめられず、入れなかった内容があれば書く）

## 自分で決めたこと
- （尺、言語、明暗の使い方、例に使った名前など）

## 補足
- 画面は HTML で作り直したもので、スクリーンショットではありません
- 直したい所があれば、場面と時刻で教えてください
```

数値は実際に測ったものを書く。測っていないことを「確認済み」と書かない。
