# 音（曲と効果音）

音は素材を使わず、ブラウザの中で合成する。曲は「区間の並び」から自動で編曲され、効果音は場面を組むときに積んだ合図の時刻で鳴る。

**作る側は音を聴けない。** だから音色や音量は、あらかじめ測って決めた値を使い、自分で作り込まない。やることは 3 つだけ: 区間を場面に合わせる、合図を動きに合わせて積む、測った数値を確かめる。聴感の確認は、報告で人に頼む。

## 1. 曲: 区間を場面に合わせる

`src/js/plan.js` の `music.sections` に、場面の雰囲気に合う種類を並べる。境目は小節の頭（120 BPM なら 2 秒の倍数）、すき間なく並べる。

| 種類 | 鳴るもの | 合う場面 |
|---|---|---|
| `intro` | 暗い和音と低い持続音、ゆっくりした鼓動。打楽器なし | 困りごと。最初の 4〜8 秒 |
| `reveal` | 和音が開け、後半からアルペジオが入ってくる | ロゴとひとこと。4〜6 秒 |
| `groove` | 基本のノリ（キック、リム、ハイハット、ベース、アルペジオ）。和音は 2 小節ごとに進む | 本編 |
| `peak` | 四つ打ち、クラップ、16 分のアルペジオ。和音は 1 小節ごと | 機能を畳みかける場面。6〜8 秒 |
| `calm` | 打楽器なし。和音と、まばらなベル | 安心させる説明、仕組みの図 |
| `build` | 静かに始まって盛り上がり、最後は連打と上昇音 | 最後のカードの直前（はじめかた等） |
| `outro` | 主和音に着地。軽いノリが続き、最後の 2 秒で鳴り終わる | 最後のカード。6 秒 |

- `hit: true` を付けた区間は、頭で低い一撃が鳴り、直前に上昇音が入る。映像も同じ時刻に大きな動き（ロゴがはまる、場面が切り替わる）を置く。付けるのは 2〜4 か所（ロゴ、盛り上がりの頭、最後のカード）
- `melody: true` を付けた `groove` には旋律（ベル）が乗る。本編の前半は付けず、後半から付けると展開が出る
- `muffle: [[67, 69.5]]` で、その間だけ曲がこもる（通信が切れる、水に潜る、といった場面）
- `bpm` は 100〜128、`key` は -2〜+3 の範囲で。変えると場面の秒数の計算も変わるので、特に理由がなければ 120 と 0 のまま

90 秒の例:

```js
sections: [
	{ from: 0, to: 8, type: "intro" },
	{ from: 8, to: 14, type: "reveal", hit: true },
	{ from: 14, to: 30, type: "groove" },
	{ from: 30, to: 58, type: "groove", melody: true },
	{ from: 58, to: 66, type: "peak", hit: true },
	{ from: 66, to: 72, type: "groove" },
	{ from: 72, to: 78, type: "calm" },
	{ from: 78, to: 84, type: "build" },
	{ from: 84, to: 90, type: "outro", hit: true },
],
```

`node render.mjs --audio` を実行すると、境目が小節に乗っていない・すき間がある・種類の名前が違う、を警告する。

## 2. 効果音: 動きと同じ場所で積む

```js
import { cue } from "./kit/cue.js";
cue("row", at, { pan: -0.4 });
```

`pan` は左右（-1〜1）。画面の左で起きたことは左、右で起きたことは右から鳴らすと、どこで起きたかが音でも分かる（左の PC の画面は -0.4、右のスマホは 0.5、など）。

| 合図 | 音 | 使う所 | 追加の指定 |
|---|---|---|---|
| `tap` | 指で押す音 | `tap()` が自動で積む | |
| `click` | マウスで押す音 | `pointer.click()` が自動で積む | |
| `type` | 文字を打つ音の連なり | 入力欄に打つ | `dur`（秒）、`n`（文字数）、`key: true`（キーボード。なければスマホ） |
| `enter` | Enter を押す | コマンドの実行、入力の確定 | |
| `send` | 送る | メッセージの送信 | |
| `row` | 行が 1 つ出る | 一覧やログに行が加わる | `hi: true`（1 オクターブ上。2 つの画面で呼び交わすとき、届く側に）、`soft: true` |
| `pop` | 弾んで出る | タイル、吹き出し、カード | `i`（0, 1, 2… と増やすと音階を上る） |
| `tick` | 小さな刻み | 切り替えスイッチ、タブ | |
| `cascade` | 音階を駆け上がる | 行が次々に出る（差分、一覧） | `n`（行数）、`step`（間隔。秒） |
| `stream` | 細かい粒 | 文章が流れてくる | `dur` |
| `ask` | 解決しない上行 | 質問や確認が出る | |
| `confirm` | 決定 | 回答する、選ぶ | |
| `done` | 完了 | 作業が終わる | |
| `success` | 明るい分散和音 | 設定の完了、成功 | |
| `check` | チェックが付く | 確認項目が 1 つずつ出る | `i`（0〜2） |
| `error` | 下がる音 | 失敗、切断 | |
| `connect` | 上がる音と和音 | つながる、復帰 | |
| `launch` | 立ち上がる | 起動、開始 | |
| `notify` | 通知の 2 音 | スマホの通知が届く | |
| `buzz` | バイブレーション | 通知の直後（0.4 秒後など） | |
| `timelapse` | 速くなる時計の刻み | 時間が過ぎていく | `dur` |
| `scan` | 上下する細い音 | 読み取り | `dur` |
| `whoosh` | 風切り | 入れ物が大きく動く、場面の入れ替わり | |
| `wipe` | 大きな風切り | `wipe()` が自動で積む | |
| `logoHit` `swell` `tag` | ロゴまわり | `logoReveal` `logoLockup` `taglineIn` `endCard` が自動で積む | |

積み方の目安:

- 画面で何かが「起きた」瞬間には、必ず何か鳴らす。逆に、起きていないのに鳴らさない
- 1 秒に 3 つ以上は鳴らさない（`type` `cascade` `stream` は 1 つと数える）。鳴らしすぎると曲を邪魔する
- 効果音の音程は曲の調に合わせてあるので、どの和音の上で鳴っても濁らない
- 一覧にない名前を書くと、警告が出て何も鳴らない

## 3. 測る

```sh
node render.mjs --audio      # out/audio.wav と、音量をそろえた out/audio-master.wav
```

表示される 2 行を読む。

```
audio  out/audio.wav  15.4s  peak -0.2 dBFS
master -16.9 LUFS / -1 dBTP  →  -15.1 LUFS / -1.2 dBTP
```

- 仕上がり（矢印の右）が **-15 LUFS 前後、ピーク -1 dBTP 前後**なら正常。書き出しのときに自動でこの値にそろえる
- そろえる前の値（矢印の左）が -20 LUFS より小さいときは、曲の区間が短すぎるか、ほとんど `intro` / `calm` になっている
- `[music]` の警告が出たら、`plan.js` の区間を直す

`tools/qa.mjs` は、できた動画の音量・ピーク・途中の無音も調べる。

系統ごとに確かめたいとき（ふつうは不要）:

```sh
node render.mjs --audio --stems pad,bass,drums,arp,melody,fx,sfx     # out/stem-*.wav
```

`kit/audio.js` の音量や音色は、測って釣り合いを取ってある（低音が出すぎない、高音がこもらない）。耳で確かめられない状態で変えると、ほぼ確実に崩れる。変えるのは、人が聴いて「ここをこうしてほしい」と言ったときだけにする。

## 4. 報告に書くこと

- 曲と効果音はコードで合成したオリジナルで、外部の素材は使っていないこと
- 音量とピークの実測値
- **聴いて確かめてはいないこと。** 曲の好みや音量の釣り合いは、聴いて判断してほしいこと。直したい点（曲を静かに、効果音を減らす、盛り上がりの位置を変える、など）があれば対応できること
