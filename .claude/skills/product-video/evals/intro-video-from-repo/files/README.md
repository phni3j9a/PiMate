# Shiftly（シフトリー）

飲食店・小売店向けのシフト調整アプリです。スタッフはスマホから希望休を出し、店長は Web の管理画面でシフトを組みます。「誰がいつ入れるか」を紙やチャットで集め直す手間をなくします。

## できること

- **希望休の提出**: スタッフはスマホのカレンダーをタップして希望休を出します。締切の 3 日前と前日に、まだ出していない人へ通知が届きます。
- **下書きの自動作成**: 希望休と、時間帯ごとの必要人数から、管理画面がシフトの下書きを自動で作ります。人数が足りない日は赤く表示されます。
- **交代の募集**: 入れなくなった日は、スマホから交代を募集できます。引き受ける人が出ると、店長に承認の依頼が届きます。
- **確定の通知**: 店長がシフトを確定すると、全員のスマホに通知が届き、各自のカレンダーに反映されます。

## 対応していないこと

- 勤怠の打刻と給与計算には対応していません。確定したシフトは CSV で書き出せるので、ほかのサービスに取り込んでください。
- 複数店舗をまたいだシフトの調整には対応していません（店舗ごとに別の表になります）。

## 動作環境

| | 条件 |
|---|---|
| スタッフ用アプリ | iOS 16 以上、Android 10 以上 |
| 管理画面 | Chrome / Edge / Safari の最新版 |

## 料金

スタッフ 10 人までは無料です。11 人以上は 1 店舗あたり月額 2,980 円（税別）です。
