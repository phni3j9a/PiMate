# 画面の構成

## スタッフ用アプリ（スマホ）

- **希望休**: 月のカレンダー。日付をタップすると希望休の印（緑の丸）が付く。上に「締切まであと 3 日」。下に主ボタン「提出する」。提出すると上部に「提出しました」と出る。
- **自分のシフト**: 確定したシフトの一覧（日付、時間帯、店舗名）。各行の右に状態（確定 / 下書き）。行をタップすると「交代を募集する」ボタンが出る。
- **交代の募集**: 募集中の一覧。ほかの人の募集には「引き受ける」ボタン。引き受けると「店長の承認待ち」になる。

## 管理画面（Web）

- **週の表**: 縦にスタッフ、横に曜日。セルに時間帯（例: 10–15）。上に「下書きを自動で作る」ボタンと、右上に主ボタン「シフトを確定する」。
- **足りない日**: 必要人数に足りない曜日の見出しが赤くなり、「人数が足りません」と出る。
- **承認**: 交代の依頼が届くと、右上のベルに件数が出る。開くと「承認する」ボタン。
