# 会話の表と全画面ビューア: Android 確認（#159）

## 仕様と幅の選択

会話では表の実幅を測り、各列の自然幅（上限240dp）で収まるなら縮めない。超過時は短い列を固定し、長い列は最小幅を確保して折り返す。最小幅でも入らなければ自然幅のまま横送りする。標準の最小幅は100dp、セルの左右余白は各8dp。文字領域の見積もり・最小幅はアプリの文字サイズと OS 文字倍率に合わせる。

標準文字・表幅320dpで、fake Host の6表（ファイル集計、短い2列、長文2列、6列、長文3列、短長混在4列）を撮影して比較。横送りが必要な表は従来5件、100dpで1件、120dpで4件。長文2列はどちらの候補でも収まるが、100dpでは長文3列と混在4列も全列が見える。本文が全角約6〜7文字で折り返し、行が約74dpになる例を見比べたうえで100dpを採用した。

会話内ではセルの長押し選択を無効にし、表の右上に「表を全画面で見る」を置く。全画面は Drawer の外で開き、同じ列幅計算を使う。セル内の文字は OS 標準で部分選択、右上のコピーはその表だけの Markdown（区切り行・装飾も含む）。戻ると会話に復帰する。表の内容・画像ギャラリー・会話に紐づく画像ローダーはメモリ内だけで渡す。

## 環境と結果

Android API 35 / x86_64、read-only `pimate35`、1080×2400・480dpi、画面幅360dp。Expo SDK 57 / RN 0.86.3。コミット `a7d3dec` の JDK 21 / x86_64 用 release APK（署名方式v2、APK SHA-256 `b339043e9a4e2092c88c60eba98824b05f56dd5e984899ad57268864979fca7f`）。loopback の fake Host のみ使用。バージョンは配布版と同じで、このAPKは配布しない。

## 再確認

1. [fake Host の手順](../apps/mobile/README.md#pcのpiなしで画面を確認する)で接続し、`md` を送る。2・3・混在4列の右端を確認し、6列では表の上からゆっくり左右へ送る。
2. セルを長押ししても選択されないこと、表から縦にドラッグすると会話が動くこと、表の外で右へ送ると一覧が開くことを確認する。
3. 右上の拡大ボタンで開き、6列の最後のセルまで横送りする。縦送りには、fake Host の応答の表に画面高を超える行数を用意する（標準見本の本文は1行）。
4. セル内の一部を選択してコピーし、Android の戻るで会話の位置が保たれたことを確認。入力欄へ貼り付けて照合し、送信せず消す。表右上のコピーボタンについても元の Markdown と照合する。
5. ライト・ダーク、OS倍率1.3でも表を開閉し、確認後は元の設定に戻す。

## 限界

今回の対象は縦向き Android エミュレーター。実機・iOS・TalkBack・画像入りセルの画像実取得・子の作業記録での操作は未検証。列幅は文字幅の近似で、フォントや OS の非線形拡大まで字数の厳密な一致は保証しない。性能計測や斜めスワイプの網羅試験は行っていない。
