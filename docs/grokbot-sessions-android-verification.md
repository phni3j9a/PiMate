# Grok Bot 起動元の区分表示: Android 確認（#110）

## 仕様と互換性

- CLI の `pimate spawn` は `origin: "grok-bot"`、スマホからの起動は `mobile`、通常の端末起動は `pc`。CLI を手動実行した場合も Grok Bot に含める。表示のための分類であり、操作権限・フォルダの信頼判断・Webhook の監視設定とは別。
- ドロワーは各ホストの通常行の下に「Grok Bot」の区画を置く。質問・子の確認待ちは全起動元を最上段の「要対応」に集め、Bot の行では起動元も示す。重複表示しない。
- `Grok Bot` で検索でき、セッションメニューの「起動元」にも表示。セッション名に Grok Bot を含むだけでは所属は変わらない。
- PC とアプリの両方の更新・Host 再起動が必要。旧 Host は新起動元の Pi を一覧から除外する。旧アプリは通常行として表示するが区分はできない。起動済みプロセスの自動移行はしない。

## 環境

Android API 35 / x86_64 の既存 AVD を **read-only・snapshot 保存なし**で起動。1080×2400、480dpi（幅360dp）、Expo SDK 57 / React Native 0.86.3。ADB は常に `emulator-5566` を指定し、接続中の Pixel 3 は操作していない。

一時ディレクトリのテスト用鍵で release APK をビルドし、エミュレーター内だけにインストール。配布用鍵・公開 APK は変更していない。実 Pi・本物の Host・本物の Webhook は使わず、loopback の fake Host（47883）だけに接続した。

| セッションメニューの起動元 | OK。`Grok Bot · PC から未接続` を表示 |

自動検証: 全体 lint / 型検査、単体715件（PC322・protocol27・mobile366）、実 Pi の faux provider による隔離 E2E 5件、PC build / pack smoke（Pi 1.2.0）、Android release ビルド。起動元・trust・認証専用 Pi の非表示・複数ホスト・要対応・検索のテストを含む。独立レビューと空表示修正の再レビューでも指摘なし。

画面・UI 階層・録画・ビルドログ・操作スクリプトはローカルの `/tmp/pimate-grokbot-qa-1TYXk6/` に保存（Git には含めない）。最終検証 APK の SHA-256: `0c20ee2f6cb1b30daf2baf833d9f2af931ae7f15b624f960223f9e4657796ca9`。版番号は配布版と同じ0.1.10だが、テスト用の別署名なので配布用ではない。

## 限界

実機・iOS・TalkBack / VoiceOver・60fpsの性能計測・Reduce Motion は未検証。動画解析用の Gemini 認証がないため、録画全体の動画解析は行っておらず、抜き出しフレームでの確認に限る。実 Grok Bot から起動して本番アプリで見る確認は、両パッケージのリリース・更新後に必要。

既知のライトテーマのナビゲーションバー問題（#46）と依存監査（#85）は変更対象外。
