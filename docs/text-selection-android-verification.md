# 回答の部分選択・コピー: Android 確認（#82）

## 仕様

- 本文・見出し・リスト項目・引用・表のセル・コードの `Text` を OS 標準の選択対象にする。回答を包んでいた長押し全文コピーの `Pressable` は削除。
- 長押し → 選択ハンドルで範囲調整 → OS の「コピー」。選択は同じ表示ブロック内に限る。段落・リスト項目・表のセル・コードブロックをまたぐ連続選択は対象外。
- 回答末尾のボタンは元の Markdown 全文、コード右上のボタンは元コード全体をコピーする。成功時は短時間チェック表示、失敗時は再試行を案内する。
- 部分コピーは表示されている文字が対象。コード内のタブは従来どおり半角スペース2個で表示され、そのまま部分コピーされる。元のタブを保つ場合はコード全体のコピーボタンを使う。
- 親チャットと子の作業記録は共通の `TranscriptRow` / `RichText` を使う。PC・プロトコルの変更や新しい依存はない。
