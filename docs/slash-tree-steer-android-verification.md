# / コマンド・セッションツリー・割り込みのみ: Android 実機確認

## 対象と環境

- PR [#41](https://github.com/phni3j9a/PiMate/pull/41)（/ コマンド）、[#42](https://github.com/phni3j9a/PiMate/pull/42)（セッションツリー）、[#43](https://github.com/phni3j9a/PiMate/pull/43)（割り込みのみ）をマージした main `56a0279`。
- 署名済み release APK（バージョン 0.1.3 / versionCode 1003、リリース未公開）。SHA-256 `f2d4c8e13b5d3dce27231f680534d6e10c3361e84536dc953bd28260739cf8d6`。インストール済みアプリと署名証明書（`fdad0d85…3ac7`）が一致することを確かめ、`adb install -r` で上書き。
- Pixel 3 / Android 11（1080×2160）。
- 接続先は隔離した開発用の Host と Pi。設定・run・abduco・Pi のエージェント設定はすべて一時ディレクトリに置き、ネットワークを使わない faux provider と、確認用の Extension コマンドを読み込んだ。端末とは `adb reverse` 経由の loopback で接続した。商用モデルは使っていない。

## 確認したこと

| 操作 | 結果 |
| --- | --- |
| `/` 入力時の候補の表示・前方一致の絞り込み・タップで挿入 | OK。キーボード表示中も入力欄の上に収まる |
| `/model` | モデル・Thinking のシートが開く |
| 未知の `/name` | モデルへ送らず、説明を出して下書きを保持する |
| Extension コマンドの実行 | 実行され、送信待ちの表示が残らない |
| `/home/x` | 普通の文章として送られる |
| セッションのメニューと `/tree` からツリーを開く | OK |
| 複数ターン後のツリー、「ユーザーのみ / すべて」 | OK。現在の枝と現在位置を表示する |
| ユーザーのメッセージへ「ここへ移動」（要約なし） | 履歴が切り替わり、その文が入力欄に戻る。元の枝もツリーに残る |
| 「ここへ移動」（要約あり） | faux で branch_summary が作られることを確認（要約の品質は対象外） |
| ラベルの保存・解除 | OK。キーボード表示中も保存できる |
| 作業中の送信 | 送信ボタンが「割り込む」になり、「後で伝える」の切り替えは無い。割り込みが本文に反映される |
| 反映前に停止 | 「届いていない可能性があります」の行が出る。入力欄が空なら「下書きへ戻す」で復元でき、自動では再送しない |
| ライト / ダーク | アプリ本体はどちらも表示に問題なし |

## 見つかった問題と限界

- ライトテーマで、Android の戻る／ホームのアイコンが白い背景にほぼ溶け込んで見えない。今回の PR はテーマやナビゲーションバーを変更しておらず、以前からある問題と思われる（別 Issue で扱う）。
- ツリーの操作シートで、キーボード表示中に下のボタンが一部隠れる。スクロールして届くかは未確認。
- 「すべて」の表示で、本文の無い system の行が1件出た（faux 環境によるものかは未確認）。
- 商用モデルでの要約・割り込みのタイミング、iOS、タブレット、文字の拡大は対象外。
- ローカル記録（スクリーンショット・ログ）は `/tmp/pimate-device-qa/` に置き、公開しない。確認後、開発用の Host・Pi・abduco・`adb reverse`・アプリに追加した開発用マシンを削除し、端末の夜間モード設定を元に戻した。
