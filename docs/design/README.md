# PiMate 画面モック

アプリのロゴ・各OS用アイコン素材は [PiMate icon kit](icon-kit/README.md) を参照してください。

スマホアプリの見た目と画面構成の基準です。仕様の正本は [docs/SPEC.md](../SPEC.md) で、このモックはSPECの「UIの方向性」と「サブエージェント」を画面にしたものです。両者が食い違う場合はSPECを優先し、モック側を直します。

## 見方

[index.html](index.html) をブラウザで開いてください（ファイルを直接開けます）。画面を選ぶと、実寸（390×844）のHTMLが開きます。

- フォントはGoogle Fontsから読み込みます。オフラインでは代わりのフォントで表示されます。
- 画像だけ見たいときは [png/](png/) を開いてください（2倍の解像度）。
- 色・文字・余白・部品のルールは [デザイントークン](html/Tokens.html) にまとめています。

## 使い方の注意

- **基準にするもの:** 色、文字サイズ、余白、ボタンの使い分け（塗りの主ボタンは1画面に1つまで）、状態の示し方、画面の構成と文言の方針。
- **例にすぎないもの:** モデル名、料金、トークン数、ファイル名、セッション名、時刻などの値。`[VERSION]` は未定の値です。
- iOSの見た目（ステータスバー、システムフォント）で描いています。Androidでは、Material Designの作法に合う範囲で置き換えてかまいません。
- `pimate attach <id>` というコマンド名とIDの形式は仮です。

## 画面一覧

| ファイル | 画面 | 見るところ |
|---|---|---|
| `Main` | チャット — 作業中 | ツール呼び出しの行、送信待ちのメッセージ、送信のタイミング（割り込む / 完了後に送信）、停止 |
| `Drawer` | ドロワー — Instance 一覧 | 要対応のグループ、マシンごとのグループ、起動元・サブエージェントの補足 |
| `Chat-Waiting` | チャット — 入力待ち | チャット内に出すPiからの質問（モーダルにしない） |
| `Chat-Edge` | チャット — 再接続と PC 側の操作 | 届いたか未確認のメッセージ、PCでの `/resume` による切り替え、下書きの送信先の確認 |
| `Chat-Attach` | チャット — PC で操作が必要 | スマホで操作できないExtensionの画面と、`pimate attach` への誘導 |
| `Sheet-Model` | モデル・Thinking シート | モデルの選択、Thinkingのレベル、コンテキストの使用量 |
| `Sheet-Session` | セッション・Instance シート | セッション操作（`/new` `/resume` `/tree` `/fork` `/compact`）、起動元、Piの終了 |
| `Review` | 変更レビュー | ターン / セッション全体の差分、この変更についての依頼 |
| `New-Pi` | 新しい Pi を起動 | マシン、フォルダ、フォルダの信頼、モデル、最初のメッセージ |
| `Chat-Subagents` | チャット — サブエージェント実行中 | 入力欄の上の要約1行（親が完了していても残る） |
| `Sheet-Subagents` | サブエージェント一覧 | 実行中と以前の実行、実行単位ごとの停止 |
| `Subagent-Detail` | サブエージェント — pi-subagents | 親からの依頼、子の作業記録、子への指示、一時停止 |
| `Subagent-Detail-Readonly` | サブエージェント — 公式サンプル | 見るだけの画面、チェーンの進み具合、全体の停止 |
| `Settings` | 設定 | マシン、通知、文字サイズ、互換性の説明 |
| `Tokens` | デザイントークン | 色・文字・サイズ・部品のルール |

## ファイル構成

| パス | 内容 | 編集 |
|---|---|---|
| `mock/*.dc.html`, `mock/canvas.json` | モックの元データ（claude.ai のデザインキャンバス形式） | ここを直す |
| `mock/support.js` | 元データをブラウザで展開するための最小限のスクリプト | 必要なときだけ |
| `export.mjs` | `html/`・`png/`・`index.html` を作り直すスクリプト | 必要なときだけ |
| `html/*.html` | 単体で開けるHTML（生成物） | 直接編集しない |
| `png/*.png` | 画面の画像（生成物） | 直接編集しない |
| `index.html` | 一覧ページ（生成物） | 直接編集しない |

## 更新の手順

1. `mock/` の `.dc.html` を直します。画面を足すときは `canvas.json` の `boards` と `order` にも追加します（一覧のグループは、`notes` の見出しより下にあるボードがその見出しに入ります）。
2. 生成物を作り直します。Chrome または Chromium が必要です。見つからない場合は `CHROME=<実行ファイル>` で指定します。

   ```sh
   node docs/design/export.mjs
   ```

3. `html/`・`png/`・`index.html` の差分も一緒にコミットします。

元のモックは claude.ai の Artifact（<https://claude.ai/artifact/2RyQi2ao7E3pt5Mzn299KY>）にもあります。所有者だけが開ける非公開のページなので、リポジトリの `mock/` を正とします。
