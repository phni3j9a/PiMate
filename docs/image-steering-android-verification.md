# 親への割り込み・画像添付: Android エミュレーター確認

## 対象と環境

- PR [#30](https://github.com/phni3j9a/PiMate/pull/30)、[#32](https://github.com/phni3j9a/PiMate/pull/32)。アプリコード `0541c42` の署名済み release APK（開発用バージョン 0.1.2、リリース未公開）。
- APK SHA-256: `a94d301dd69ead4b97511cbd0bd9575b75e3db82c4e3a7393311864a4c138707`。
- Android API 35 / Google APIs / x86_64、専用の一時 AVD `pimate-image-qa`。1080×2400、420dpi（幅約411dp）、小画面は960×1600（幅約366dp）。
- 実機とは分離し、ADBは `-s emulator-5566` を指定。OSピッカーには合成テスト画像だけを投入。
- 接続先は `dev-fake-host.mjs` の一時コピー。受付応答、busy状態保持、モデル非対応エラー、応答前切断、旧RCのcapability欠落を注入。実Piのキュー処理・実モデルの画像理解をこの確認で代替しない。

## 確認したこと

| 操作 | 結果 |
| --- | --- |
| OS写真ピッカーを開く・キャンセル | アプリへ戻る。写真ライブラリ全体への許可ダイアログなし |
| 写真選択・削除・再選択 | サムネイルと削除操作を確認。1800×1100のJPEGが送信時30,179 bytesへ縮小された |
| idle時に画像だけを送る | `text: ""` と画像が送信され、受付通知と実履歴由来の画像を表示。下書きはクリア |
| busy時に「割り込む」を選ぶ | シート・ボタン表示が切り替わり、テキストのみ／画像つきの要求に `deliverAs: "steer"` が入る |
| busy時に「後で伝える」を選ぶ | 本文＋画像の要求に `deliverAs: "followUp"` が入る |
| 受付後 | 画像は受付通知のみ。テキストのみのsteerは「割り込み待ち」。画像の仮吹き出しは残さない |
| モデル非対応応答 | 「画像対応モデルを選んでください」と表示し、本文・画像を保持 |
| 応答前に通信切断→再接続 | 「届いたか未確認」と手動の履歴確認を案内。本文・画像を保持し、再接続・前景復帰後にも追加のprompt要求なし |
| 旧RC（`promptImages`なし） | PC側更新とPi再起動を案内。＋ではピッカーが開かず、テキストのみの送信は可能 |
| キーボード・前景復帰 | 入力欄がキーボード上に収まり、プロセスを終了しない前景復帰では下書きを保持 |
| ライト／ダーク・幅約366dp | 入力欄、画像、送信モード、停止・送信ボタン、シートの明確な重なり・欠けなし。狭幅ではコンテキスト表示を省略 |

## 記録と限界

- ローカル記録: `/tmp/pimate-emulator-qa/`。スクリーンショット、要求ログ、操作録画（`flow-final.mp4` など）と抽出フレームを保存。ペアリングコードを含むログは公開しない。
- 録画からシート・ピッカー・キーボード遷移のフレームを確認。動画解析用Gemini認証がなく、通常速度での動画解析・全フレーム検査・60fps性能測定は未実施。滑らかさの保証ではない。
- ダークはOS設定変更後のアプリ再起動で確認。実行中の即時テーマ追従、文字拡大、タブレット、iOSはこの確認の完了項目に含めない。
- 商用実モデルの画像理解、Pi本体での実際の割り込みタイミングは別検証。実Pi＋ローカルfaux providerを通す画像再変換・配送のE2EはPR #32の検証欄を参照。
- 検証後は今回のHost・エミュレーター・一時AVD・エミュレーター用reverseを終了／削除する。既存AVD・接続中の実機は変更しない。
